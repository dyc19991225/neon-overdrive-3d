# Mech Builds & Progression（机甲构筑、经验磁吸与成长曲线）

**Status:** designed · **Updated:** 2026-11-25 · [GDD](../../GDD.md)

承载单局内的角色差异化、属性计算底层、吃豆升级爽感与三选一构筑策略。直接支撑核心支柱 **「肉眼可见的质变进化」**，采用三层清晰属性修改器栈杜绝后期数值崩坏或卸装/增益失效 Bug。

## Rules
1. **三层属性修改器栈（Modifier Stack）：** 机甲基础面板为唯一存储真值，所有实时属性按以下公式派生重算：
   `最终属性 = clamp((基础值 + Σ固定加成 Flat) × (1 + Σ同层百分比 Pct) × Π独立乘区 More, 下限, 上限)`。
   升级最大生命值时，**同步等额增加当前生命值**（既是扩容也是即时小额救急）。
2. **护甲减伤采用线性有效生命公式：** `实受伤害 = max(1, round(原始伤害 × 50 / (50 + 护甲)))` `[ASSUMPTION]`（每 1 点护甲稳定提升 `2%` 有效生命值，叠再高护甲也不会出现 0 伤无敌 Bug），受击后获得 **`0.35 s` 无敌保护帧（I-frames）** 防止被怪海同帧秒杀。
3. **先外推再吸入的磁吸晶体（Push-back XP Magnet）：** 能量晶体进入机甲拾取半径时，先朝反方向弹性外推 `0.8 m`（耗时 `0.09 s`），随后以指数加速弧线汇入机身并按连吃计数逐级升高合成器清脆音阶（Pitch Escalation）。场地上掉落超过 `400` 枚散落低级晶体时，远端晶体自动聚合成单枚高价值赤金晶簇，兼顾满屏视觉与零掉帧。
4. **相位冲刺（Dash）联动：** 按下 `Space` 朝移动方向瞬移 `5.5 m`（无敌 `0.22 s`，冷却 `2.8 s` `[ASSUMPTION]`），并在冲刺终点激起一次小范围脉冲，临时将拾取半径扩大 **1.8×** 持续 `0.6 s`，鼓励冲入怪缝帅气“收菜”。
5. **升级三选一权重与保底防卡手：**
   - 已持有武器/芯片的升阶权重高于未持有新装备（`1.6 : 1.0`），帮助玩家稳定朝 8 级超武推进。
   - 若玩家已持有某把武器但尚未拿到其配对被动芯片，该配对芯片在卡池中的出现权重自动提升至 **`2.0×`（软保底）** `[ASSUMPTION]`，减少凑不出超武的纯看脸挫败感。
   - 每局初始自带 **2 次重随（Reroll）** 与 **1 次封禁（Banish）** 机会 `[ASSUMPTION]`。

### 2. 12 分钟单局升级节奏与经验曲线 `[ASSUMPTION]`

采用分段平滑增长公式：`升至下一级所需 XP(L) = round(8 + 6 × (L - 1) + 1.4 × (L - 1)^1.65)`（预计 12 分钟通关等级落在 **Lv 32–Lv 40**，足够升满 2–3 把超武 + 多枚核心芯片）：

| 等级区间 | 单级所需 XP | 目标升级间隔 | 阶段体验目标 |
|---|---|---|---|
| **Lv 1 → Lv 6** | 8 → 48 XP | 每 **12–20 秒** 升 1 级 | 开局极速高频反馈，前 90 秒迅速凑齐 3 把趁手武器 |
| **Lv 7 → Lv 18** | 58 → 245 XP | 每 **20–30 秒** 升 1 级 | 锁定核心流派，在第 5–6 分钟将主力武器推上 Lv 8 合成首把超武 |
| **Lv 19 → Lv 35+** | 265 → 680+ XP | 每 **25–40 秒** 升 1 级 | 配合中后期高价值品红晶簇与全屏磁铁道具，持续合成第 2、第 3 把超武冲刺终局 |

## Edge cases
- **连续吃大晶簇连升多级：** 经验溢出部分完整保留并排入「待结算升级队列」；升级三选一全息面板弹出时将 `timeScale` 平滑降至 `0.0` 暂停战斗模拟，选完后给予 `0.4 s` 半速缓冲恢复手感，避免切回瞬间撞怪暴毙。
- **武器与芯片全满级后继续升级：** 当全身 12 槽全部升至上限（含超武进化完毕）后，后续每次升级直接提供二选一：「立即恢复 `35%` 生命」或「超频注入：本局全伤害永久 `+4%`」。

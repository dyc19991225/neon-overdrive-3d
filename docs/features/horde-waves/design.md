# Horde Waves & Spawn Curve（怪潮波次曲线与同屏预算）

**Status:** designed · **Updated:** 2026-11-25 · [GDD](../../GDD.md)

掌控整局 **12 分钟** 的情绪心流曲线：从开局轻松割草热身，到中期特种敌机逼迫走位，再到后期千怪同屏、满屏超武与泰坦 Boss 决战。直接服务于核心支柱 **「千怪同屏依然刀刀到肉、稳 60 帧」**（见决策 D-001、D-002）。

## Rules
1. **视野外环状刷怪：** 普通敌机始终在玩家当前坐标外圈 **半径 `24 m–30 m`** 环带生成（略大于斜俯视相机可视边界 `20 m`），保证怪物绝不凭空闪现在玩家脸上。
2. **远距自动迁跃（Despawn & Recycle）：** 当玩家高速冲刺拉开距离，落后超过 **`38 m`** 的普通敌机不销毁也不丢失波次配额，而是静默重定位至玩家前方扇区外圈，维持压迫感。
3. **最低同屏保底（Minimum Quota）：** 每个时间段设有「同屏最低存活数」与「每秒刷怪速率」；当玩家超武清屏导致场上怪物低于保底值 `50%` 时，刷怪器自动进入 **2.5× 急速补怪**，确保火力越猛、割草越爽、经验越多。
4. **特殊战术编队事件：** 除常规追击怪外，按固定时间戳触发「高速冲锋队列（直线掠过屏幕）」与「环形合围网（包围圈缓慢向内收缩，逼迫玩家集中火力撕开缺口或用相位冲刺突围）」。
5. **精英与阶段 Boss：** 每逢 **2:00 / 6:00 / 10:00** 刷出护盾精英卫队长（必掉超导进化宝箱）；每逢 **4:00 / 8:00 / 12:00** 降临巨型阶段 Boss 并升起半透明霓虹竞技场围栏（限制逃逸半径在 `22 m` 内直至击杀 Boss）。

### 3. 渲染与模拟性能预算（`three.js` r187）

| 指标项 | 硬性预算上限 | 实现策略 |
|---|---|---|
| 同屏活跃敌机上限 | **1,200 台** | 按兵种拆分为 4–5 个 `THREE.InstancedMesh`，每帧仅更新 `instanceMatrix` 与受击白闪 `instanceColor` |
| 寻路与防重叠开销 | **CPU ≤ 2.5 ms / 帧** | 纯 2D 平面向量朝向玩家 + 基于固定网格空间哈希（Spatial Hash Grid，格宽 `2.0 m`）的邻域软排斥，零重型 3D 物理引擎开销 |
| 目标帧耗时 | **60 FPS（`p95 < 16.67 ms`）** | 像素比上限 `Math.min(devicePixelRatio, 1.5)`，零运行期 GC 分配（预分配 `Float32Array` 结构体数组 SoA 管理敌机状态） |

## Edge cases
- **12:00 终局 Boss 战超时：** 12:00 泰坦核心登场后停止刷新普通杂兵潮（仅保留 Boss 召唤的自爆蛛群补给弹药/晶体），避免杂兵挤占满额对象池导致 Boss 技能失效。
- **自爆蛛连锁反应：** 自爆蛛引爆对半径 `3.2 m` 内其他敌机同样造成 `60` 点友军伤害 `[ASSUMPTION]`，鼓励高手故意贴身勾引自爆蛛完成连锁炸群。
